# 🦇 Projeto Individual - Castlevania Legacy

## 📜 Sobre o Projeto
Este repositório contém o meu Projeto Individual desenvolvido para o curso de Análise e Desenvolvimento de Sistemas da SPTech. O tema é focado exclusivamente na franquia Castlevania, celebrando os clássicos de exploração 2D: *Symphony of the Night* (PS1) e a inesquecível trilogia do Game Boy Advance (*Circle of the Moon*, *Harmony of Dissonance* e *Aria of Sorrow*). 

O objetivo principal deste desenvolvimento é consolidar o aprendizado individual, aplicando na prática os conceitos técnicos de todas as disciplinas do semestre, ao mesmo tempo em que exploro um grande gosto pessoal pelo universo do jogo.

## ⚙️ Funcionalidades
O website foi projetado com as seguintes funcionalidades (com a possibilidade de novas features serem adicionadas em breve):
* **Página Home:** Um ambiente temático apresentando o contexto dos jogos abordados.
* **Cadastro e Login:** Tela para inserção de dados dos usuários, com validações de formulário ativas.
* **Dashboard Analítica:** Área dedicada à visualização de indicadores de pesquisa e dados relacionados ao tema.

## 💻 Tecnologias e Arquitetura
O projeto integra diferentes camadas e disciplinas do semestre, utilizando as seguintes tecnologias:
* **Frontend:** Desenvolvimento da interface e validações do lado do cliente utilizando HTML, CSS e JavaScript.
* **Backend:** Construção de uma API em NodeJS para gerenciar o cadastro e a comunicação com o banco.
* **Banco de Dados:** Modelagem de dados (com modelo lógico e relacionamentos), utilizando comandos SQL em um banco hospedado isoladamente em uma Máquina Virtual (VM) Linux.
